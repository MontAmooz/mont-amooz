# ADR-0011 — تغییر نام پروژه به «مُنت‌آموز / MontAmooz»

- **Status:** ACCEPTED
- **Date:** 2026-11-01
- **Supersedes:** نام موقت «OpenEdu Git» (در README، repo، org و تمام اسناد)

## Context

پروژه از ابتدا با نام موقت «OpenEdu Git» شناخته می‌شد — نامی که ریشه در الهام
Git-inspired داشت اما نشان تجاری نبود، هویت مستقل نداشت، و در بازار ایران
قابل ثبت و تمایز نبود. با نزدیک شدن به فاز beta، نام نهایی انتخاب شد:
**مُنت‌آموز** (ترکیب «مُنت» از نام بنیان‌گذار + پسوند «آموز» به معنای آموزش).

## Decision

- **نام فارسی رسمی:** مُنت‌آموز
- **نام لاتین رسمی:** MontAmooz
- **Slug برای repo/package:** `mont-amooz` (repo) / `montamooz` (package)
- **دامنهٔ موقت (self-hosted beta):** `amooz.m0nt.ir` (دامنهٔ مستقل `montamooz.ir` در آینده بررسی می‌شود)
- **GitHub org:** `MontAmooz`
- **Session cookie:** `ma_session` (قبلاً `oeg_session`)
- **Emails دمو:** `@montamooz.ir` (قبلاً `@openedu.ir`)

ADRهای 0001 تا 0010 محتوای فنی خود را حفظ کرده‌اند (ارجاع نام‌ها به جدید
به‌روز شد و هرکدام یک نکتهٔ تغییر نام در ابتدا دارند). اسناد آرشیو در
`docs/archive/2026-10-pre-reconciliation/` دست‌نخورده می‌مانند — آن‌ها سند
تاریخی هستند، نه سند زنده.

## Consequences

**(+)** هویت مستقل، قابلیت ثبت رسمی، slug قابل حفظ در بلندمدت.
**(−)** یک breaking change کوچک: session cookie name تغییر می‌کند (کاربران فعلی
خارج می‌شوند — در این مقطع کاربر واقعی نداریم، پس safe است). URL قدیمی GitHub
301 redirect می‌شود (به‌مدت ~۹۰ روز)، ولی لینک‌های خارجی باید به‌روز شوند.
**(−)** در صورت اشتباه در انتخاب نام، برگشت به این نقطه گران است. تصمیم با
تصویب بنیان‌گذار قطعی است.

## Migration plan

همین PR (P6) — بدون فاز جداگانه. **هر تغییر دیگر بعدی به نام جدید ارجاع می‌دهد.**
یادداشت اجرایی: تغییر نام org در گیت‌هاب از رابط وب انجام می‌شود (REST API این
فیلد را تغییر نمی‌دهد) — تا انجام آن، مسیرهای CI از `OpenEduGit/mont-amooz`
استفاده می‌کنند و پس از rename به `MontAmooz/mont-amooz` ارجاع داده می‌شوند
(۳۰۱ ریدایرکت در فاصلهٔ بین دو حالت کار می‌کند).

## Review trigger

- اگر مسئلهٔ حقوقی/ثبت علامت تجاری پیش آید
- اگر اجتماع کاربری نام دیگری را ترجیح دهد
- بازنگری در هر فاز بزرگ بعدی
